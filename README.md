# Mindful-Feed-Engine
MindfulFeed is a C++-based welfare-first content recommendation engine designed to reduce digital fatigue and excessive scrolling. It uses Trie-based content filtering, Nutritional Scoring, Max Heap ranking, FIFO Queue session control, and OOP concepts to prioritize meaningful content and encourage mindful digital consumption.

## Project Status

Project under development.

## Technology

- C++
- Object-Oriented Programming
- Trie
- Max Heap
- Token Bucket
